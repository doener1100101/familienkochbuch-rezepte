# Familienkochbuch – Rezepte

Rezept-Speicher für die Familienkochbuch-App.

- `Rezepte/<Name>.md` – ein Rezept pro Datei (Kopfbereich mit Eigenschaften + Abschnitte Zutaten, Zubereitung, Notizen, Kochlog)
- `Rezepte/Bilder/<Name>.jpg` – Titelbild, im Rezept eingebunden mit `![[<Name>.jpg]]`

Die App liest diesen Ordner direkt. Neue Rezepte und Korrekturen pflegt Claude über die tägliche Aufgabe ein (Einsendungen an rezept@unsbu.de).
Jede Änderung ist in der Versionsgeschichte nachvollziehbar und kann rückgängig gemacht werden.
